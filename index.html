Projects

Most recent work

Expense Approval Automation Middleware

Zoho Catalyst middleware: when an expense is approved, it generates an XLSX file in Catalyst Stratus and a PDF in SharePoint, and stores the expense data and SharePoint URL as a Data Store row. The XLSX is then converted to .txt and marked Pending. A custom Catalyst API delivers the file to the network folder (GET), and the same API updates the status to Success (POST).

LaClinica External CRM Integration API

A Catalyst REST API that lets the LaClinica department's external CRM push records as JSON. The embedded blob string is converted to a PDF in SharePoint, and the JSON (without the blob) plus the SharePoint URL is saved to the Data Store. The JSON is then converted to .txt, marked Pending, delivered to the network folder and marked Success through the same GET/POST API.

Cross-Suite Procurement Management

Centralized enterprise supply chain channels by binding Zoho Projects, Desk and CRM through secure webhooks and custom Deluge scripts. Multi-vendor RFQs are generated straight from project task boards, with bidirectional navigation and live updates across modules.

Serverless Outlook Synchronization

Contact, email and calendar sync built with Python on Zoho Catalyst serverless functions. Integrates Microsoft Graph API with tailored OAuth handling and a 5-minute cron schedule to stay safely below enterprise API rate limits.

Automated ERP Middleware Pipeline

Middleware using Python Watchdog that tracks file-system updates from AXCEPTA ERP and securely processes incoming data into Zoho CRM, with deduplication and Sales/Purchase Order syncing, feeding executive dashboards in Zoho Analytics.

Custom Zoho Sigma Tracking Dashboard

Interactive tracking interface built with HTML, CSS, JavaScript and Bootstrap as a Zoho Sigma extension, giving stakeholders full visibility of live milestones, threaded comments and project delivery status.
